CY · 星间档案｜产品需求文档（PRD）

1. 项目目标

面向专业实习课程，制作一个具有个人介绍、作品展示、文章阅读和内容管理功能的个人网站。采用深色星空视觉，电脑和手机均能访问；在 Vercel 或 Cloudflare Pages 发布后取得可访问地址，并提供真实页面截图。

个人信息尚未提供，因此默认使用“CY”“学生开发者”等可编辑示例。学校、履历和邮箱不作虚构；Todo 与 ImageGrab 为已有练习项目，项目介绍以实际能力为准。

2. 用户与场景

用户主要场景
访客浏览个人简介、技能与项目；阅读项目详情和博客；查看公开联系方式
网站维护者登录演示后台，更新个人资料、技能、项目、文章及站点信息；返回前台确认修改
课程验收者查看三份文档、网站功能、部署网址及截图

3. 功能需求

3.1 前台

  • 首页包含个人简介、关于我、技能、项目、博客、联系方式。
  • 星点背景与清晰的卡片层级构成视觉主题；导航可快速跳转对应区域。
  • 项目卡片打开站内详情页 /projects/:id，展示说明、标签与两类可选入口：在线体验 / 项目官网、查看源码。Todo 提供在线体验，ImageGrab 提供插件官网及各自 GitHub 源码。
  • 文章卡片可打开 /blog/:id，展示标题、日期和 Markdown 正文；未发布文章不对访客展示。
  • 缺失的联系方式应明确提示尚未填写，避免出现虚构邮箱或失效操作。
  • 未找到的资源应显示可理解的提示并提供返回入口。

3.2 内容管理后台

路由功能
/admin/login演示账号登录、错误提示
/admin管理概览与快捷入口
/admin/profile编辑姓名、身份、简介、详细介绍、邮箱、GitHub、所在地
/admin/skills新增、修改、删除技能
/admin/projects新增、修改、删除项目，编辑在线地址和源码地址
/admin/posts新增、修改、删除文章及发布状态
/admin/settings修改站点标题与描述
  • 保存后显示操作结果，前台重新读取已保存内容。
  • 必填字段及格式由表单校验，错误反馈与对应字段关联。
  • 删除前二次确认；取消删除不改变内容。
  • 登录会话设置有效期；退出或过期后再次进入后台应要求登录。

4. 数据与边界

内容统一通过 src/api 访问，以 localStorage 模拟存储。相同站点、相同浏览器中的刷新及重新打开页面可以保留修改；更换浏览器、设备或域名后不会同步。清除网站数据会移除本地修改。旧版未编辑的默认项目会一次性补充最新在线链接与源码链接；自定义内容、已删除项目和迁移后主动清空的链接不会被自动补回。

登录为课程演示功能，使用密码摘要比较与限时会话，但全部代码在客户端运行，不构成真实后台认证，也不能保护敏感数据。不得存放密码、身份证件等私人信息。需要公共内容跨设备更新时，应另行接入数据库、服务端认证与权限控制。

5. 体验要求

  • 深色星空主题，主要文字与背景保持足够对比度。
  • 页面适配 375px 手机宽度及常见桌面尺寸，避免水平滚动。
  • 表单有明确标签，交互支持键盘，焦点可见。
  • 遵守 prefers-reduced-motion，减少用户不需要的动画。
  • 外部链接使用安全打开方式，内容展示不得执行注入脚本。

6. 验收标准

  1. 首页所有栏目和项目、文章详情均可访问；不存在空白页面或明显布局溢出。
  2. 未登录访问后台会转到登录页；错误密码有提示；正确账号可登录并退出。
  3. 修改个人简介后，前台显示新内容；刷新后内容仍在当前浏览器保留。
  4. 技能、项目、文章可以增删改；取消删除不会丢失内容，未发布文章不出现在前台。
  5. Todo 与 ImageGrab 详情分别提供正确在线地址和源码入口；旧数据升级保留自定义及删除结果。
  6. 构建通过；部署后的首页及深层路由刷新可访问。
  7. 提交三份文档内容截图、线上前台与后台截图，以及实际部署网址。

7. 交付范围

交付源代码、PRD.md、TECH_DESIGN.md、AGENTS.md、运行部署说明与实际截图。课件使用 TECH_DESIGN；作业截图中的 TECH_DESIN 按同一技术设计文档理解。截图和部署地址须在实际验证后填写，不能用效果图代替。
